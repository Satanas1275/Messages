# Liquid Messages

Application Android de démonstration construite avec Jetpack Compose et `io.github.kyant0:backdrop`.

## Lancer le projet

1. Ouvrir ce dossier dans Android Studio Ladybug ou plus récent.
2. Effectuer la synchronisation Gradle.
3. Lancer la configuration `app` sur un émulateur Android 8.0+.

L’interface contient une liste de conversations issue du fournisseur SMS Android, une recherche, des menus flottants et des surfaces Liquid Glass. L’application demande les permissions SMS et le rôle d’application SMS par défaut afin de lire, recevoir et envoyer de vrais SMS localement, sans serveur.
